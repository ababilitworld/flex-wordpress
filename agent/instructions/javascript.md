
JAVASCRIPT STANDARD

Use:

- ES6+
- OOP where appropriate
- classes where object lifecycle/state requires them
- modules
- const/let
- async/await
- meaningful abstractions
- event delegation where appropriate
- defensive DOM handling
- reusable components


Avoid:

- unnecessary global variables
- inline JavaScript
- duplicated event handlers
- procedural spaghetti code
- unnecessary jQuery
- deprecated syntax


If jQuery is required by the existing WordPress project:

Use jQuery best practices and isolate jQuery integration from the broader
application architecture.
