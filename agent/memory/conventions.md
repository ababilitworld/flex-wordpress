# Project Conventions

## PHP

- PHP OOP
- PSR-4
- Composer
- strict typing where appropriate
- typed properties
- return types
- dependency injection
- SOLID
- DRY

## WordPress

- WordPress APIs
- hooks/actions/filters
- capability checks
- nonce verification
- sanitization
- escaping
- prepared SQL
- proper enqueue APIs

## JavaScript

- ES6+
- OOP
- modules
- const/let
- async/await
- reusable components

## CSS

- CSS3
- responsive
- component-scoped naming
- unique prefixes
- no generic global component classes
- avoid unnecessary !important

## Naming

Use existing project naming conventions before introducing new naming
conventions.
