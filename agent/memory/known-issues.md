# Known Issues

## Pagination

Transaction List pagination previously failed to render pagination links.

Status:

Resolved.

Root Cause:

Pagination data was not correctly propagated from Query to Template.

Required Behavior:

Pagination links must be generated by the Pagination component and made
available to the presentation layer.

---

## Template Signature

Base Template requires:

prepare_items_for_display(array $items = []): array

Concrete Templates must remain compatible with the Base Template signature.
